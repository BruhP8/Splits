# Metal Eden Demo Challenge - Autosplitter

### **[LiveSplit](https://github.com/LiveSplit) empty splits files for each category available on [Speedrun.com](https://www.speedrun.com/escape_from_school).**

### Splits:
- Level 0 : Crash Course
- Level 1 : Paradise Lost

### Compatibiliy:
- Works with the [autosplitter](https://github.com/Zeuba-Speedruns/AutoSplitters/tree/main/Metal%20Eden%20Demo%20Challenge) available in [LiveSplit](https://github.com/LiveSplit).
- Works with these valid [layouts](https://github.com/Zeuba-Speedruns/Layouts/tree/main/Metal%20Eden%20Demo%20Challenge) for a run submission on [Speedrun.com]([https://www.speedrun.com/escape_from_school](https://www.speedrun.com/challenges/9x32q3l6-Metal_Eden-metal-eden-demo-speedrun-challenge)).
